# Paper 1 Exam Practice

Standalone GitHub Pages pack for the SKH Holy Carpenter Secondary School English department HKDSE Paper 1 Quest Hub.

Live site: https://skhhcss-eng.github.io/paper-1-exam-practice/

Copied from [SKHHCSS-ENG/SKHHCSS-ENG.github.io](https://github.com/SKHHCSS-ENG/SKHHCSS-ENG.github.io) `main`, path `learning-materials/paper-1-exam-practice/index.html`. The source folder contains only that file. It does not reference parent paths (`../`), `/learning-materials/`, or shared Eng site CSS/JS, so nothing was rewritten and no shared chrome was vendored.

Tailwind (`cdn.tailwindcss.com`) and Google Fonts stay as absolute CDN links, the same as on the Eng site.

`.nojekyll` is present so GitHub Pages serves `index.html` as static HTML. The hub’s cloze blanks use `{{b1}}`-style tokens, which Jekyll would otherwise treat as Liquid.
